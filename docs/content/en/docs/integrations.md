OpenSOHO can exchange data with other software on your network.
Integrations are either **official** (supported as part of OpenSOHO) or **community** (contributed and supported by community members).

This does not have an effect on the code quality.
However, it is not a setup used by the main OpenSOHO author, so you'll be dependent on the plugin author to fix issues if you would encounter them.

| Integration                         | Type      | Description                                                                 |
|-------------------------------------|-----------|-----------------------------------------------------------------------------|
| [Home Assistant](/docs/home-assistant/) | Official  | Home Assistant integration |
| [OPNsense](/docs/opnsense/)         | Community | OPNsense DHCP leases.           |
